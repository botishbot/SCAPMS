SCAPMS README assets

Extract this ZIP into the root of your local SCAPMS repository, preserving folders.
It will create:
- screenshots/ (8 application screenshots)
- docs/diagrams/ (3 UML/architecture diagrams)

Then from the repository root run:
  git add screenshots docs/diagrams
  git commit -m "Add application screenshots and UML diagrams"
  git push origin master

The existing README image references use the screenshots/ filenames above.
